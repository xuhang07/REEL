# Image purpose: reference asset

The image will be reusable visual evidence in a video memory slot, not the
video's complete first frame.

- Center the declared subject or asset role and make its stable identifying
  features, materials, colors, proportions, and relevant wardrobe clearly
  readable.
- Avoid unrelated people, duplicate subjects, occlusion, extreme perspective,
  motion blur, embedded text, and scene-specific action that would contaminate
  reuse.
- Include enough neutral context for a coherent image, but do not turn it into
  a story beat or imply that its composition must be copied as frame zero.
- The selected result must later be consumed as a video memory slot, never as a
  condition unless it was generated in a separate `first_frame` group.
