03 / The idea

Memory planning,
independent of the backend.

REEL retrieves visual evidence, creates missing references, reviews candidates, and updates memory. Adapters translate its plans for each video backend.

Retrieve relevant evidence→Evaluate the candidate→Evolve visual memory
